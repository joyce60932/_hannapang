# 系列規格：故事型長文・幣圈教官（@_hannapang）

> 參考來源：@andrewhan233 的故事型長文，**只借架構，故事與題材一律自己寫**。
> 人設：Hanna 龐玉涵｜教路人交易的幣圈教官 — 理性而溫暖、大女主、**給工具不給答案**。
> 用途：篩選「想學習的人」。

## 7 段架構 → 8 頁分配
| 頁 | 內容 | 作用 |
|---|---|---|
| P1 | 封面：反常識鉤子 ＋「看完你會知道＿」 | 承諾吸引點開 |
| P2 | 故事（上）——前半不提交易 | 篩選讀者 |
| P3 | 故事（下） | 留張力 |
| P4 | 轉折：「想想你上次＿」＋具體失敗行為 | 「在說我」 |
| P5 | 比喻金句（故事×交易接起來） | 可截圖收藏 |
| P6 | 一條可執行規則（1%風險／系統流程） | 給工具不給明牌 |
| P7 | 自己的真實經歷／學生案例 | 可信度 |
| P8 | 工具（檢查表）＋分享 CTA＋私訊「+6」 | 降低分享門檻、導流 |

## 固定元素
- 版型：模板 A（黑金滿版真人照），頂欄 `幣圈教官`＋頁碼 `01｜08`，署名 `@_hannapang`
- 關鍵字用 `*星號*` 上鵝黃金
- 主題標籤：`#幣圈教官`（＋ #龐玉涵）
- 結尾一定：分享台詞 ＋「私訊 +6 領工具」＋「不構成投資建議」

## 帳號漏斗
- 擴大觸及：生活比喻／熱點（買菜、蘋果價講 K 線）
- 篩選受眾：故事型長文、知識卡（本系列）
- 轉換：盲點解析短影音、置頂留言、私訊「+6」

## ⚠️ 合規（交易教學，比理財觀念更嚴）
不喊單、不報明牌、不保證獲利；只給觀念＋工具＋止損紀律；每篇附「不構成投資建議」。
